## 실행 방법

설치할 것이 없습니다. 서버·API 키·빌드 과정 없이 브라우저만 있으면 됩니다.

- **온라인**: https://aebonlee.github.io/data09-02/
- **로컬**: 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
  - 간이 서버로 열어도 됩니다: 폴더에서 `python3 -m http.server 8000` → `http://localhost:8000`

처음 열면 데이터가 비어 있습니다. 「오늘의 문제」 화면이나 「데이터」 메뉴의 **「예시 데이터 불러오기」** 를 누르면 화면 확인용 가상 기록(2일치 20문제, 일부 답안·평가)이 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다. 예시 문제는 교재에 흔한 일반 주제를 문제 형태로만 적은 것이고, 답안·평가·모범답안 칸은 자리표시 문구입니다.

**하루 학습 흐름**

1. 「오늘의 문제」 → 출제 프롬프트 복사 → ChatGPT·Claude 등 AI 대화창에 붙여 넣기 → 받은 답변을 붙여 넣고 「영역별로 나누기」 → 저장 (교재·기출에서 옮길 때는 「직접 입력하기」)
2. 영역 카드를 눌러 서론·본론·결론 칸에 답안 작성 (자동 임시저장) → 「답안 제출」
3·4. **AI 평가와 모범답안** — 둘 중 하나로 합니다.
   - **자동 모드(선택)**: 「데이터」 메뉴에서 본인 OpenAI API 키를 넣어 두면, 답안을 제출하는 순간 AI 가 네 관점 평가와 모범답안을 작성해 저장합니다. 키는 이 브라우저에만 저장되고 화면에는 가려서 보이며 「키 삭제」로 지웁니다. 요금은 본인 OpenAI 계정에 청구됩니다.
   - **키 없이**: 3단계의 「통합 프롬프트」를 한 번 복사 → AI 답변 전체를 붙여 넣기 → 「3·4단계로 나누기」 → 확인 후 「평가·모범답안 저장」. (예전처럼 평가·모범답안을 따로 받는 방식도 접어 두었습니다.)

- 데이터는 **이 브라우저(localStorage)에만** 저장됩니다. 기기를 바꿀 때는 「데이터」 메뉴의 엑셀 내보내기/가져오기를 씁니다.
- 예시 파일: `samples/예시데이터_가스기술사학습.xlsx`(시트 3개) · `예시데이터_학습기록.csv` · `예시데이터_영역별현황.csv`. 모두 가상 데이터입니다.
- 영역·평가 관점·평가 기준·카드 양식은 `js/config.js` 한 곳에서 고칩니다.
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음) · 예시 파일 다시 만들기: `node scripts/make-samples.js`
- 기사 목록 손으로 갱신: `node scripts/fetch-news.mjs` (GitHub 에서는 Actions → 「가스사고 기사 목록 갱신」 → Run workflow)

## 수업이 끝난 뒤에도 계속 쓰기

- **가스사고 기사**는 GitHub Actions 가 매일 07:10(한국 시각)에 새로 받아 더합니다. 지금 수록된 기사로 끝나지 않습니다. 기사 화면 맨 위에 마지막 갱신 시각이 보입니다.
- **매일 학습문제**는 이 브라우저에서 만듭니다. 자동 모드 키가 있으면 「오늘의 문제」를 열 때 AI 가 자동 출제하고, 없으면 출제 프롬프트를 ChatGPT 에 붙여 넣습니다. 저장소 공개 여부와 관계없이 계속 됩니다.
- 이 저장소는 강의 종료 후 비공개로 바뀝니다. 비공개가 되어도 사이트는 열리지만 언제까지 유지될지 약속할 수 없으니, **계속 쓰시려면 그 전에 Fork** 하십시오. Fork 한 곳에서는 기사 자동 갱신이 본인 계정으로 계속 돕니다.
  1. 이 저장소 오른쪽 위 **Fork** → 본인 계정에 복사
  2. Fork 한 저장소 **Actions** 탭 → 「I understand my workflows, go ahead and enable them」 → 왼쪽 「가스사고 기사 목록 갱신」 → (보이면) 「Enable workflow」 → 「Run workflow」로 한 번 실행
  3. **Settings → Pages** → Source 「Deploy from a branch」, Branch `main` / `(root)` → Save → 1~2분 뒤 `https://<내 아이디>.github.io/data09-02/`
  4. 주소가 바뀌면 브라우저 저장 데이터가 따라오지 않습니다. 옮기기 전에 지금 주소에서 「데이터 → 엑셀로 내보내기」, 새 주소에서 「가져오기」. 자동 모드 키도 새 주소에서 다시 넣습니다.
- 공개 저장소의 예약 실행은 60일 동안 저장소 활동이 없으면 GitHub 가 멈출 수 있습니다. 기사 갱신이 멈췄으면 Actions 탭에서 다시 켜십시오.

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 일일 모의시험 출제 | 완료(반자동) | 10개 영역 출제 프롬프트 생성(영역별 최근 20문제를 넣어 겹치지 않게 요청) → AI 답변 붙여넣기 → 영역별로 나눠 저장. 직접 입력도 가능. 이전 문제와 비슷하면 경고. 날짜를 바꿔 다른 날 세트도 만듦 |
| 답안 작성 화면 | 완료 | 서론·본론·결론 칸, 입력 중 자동 임시저장 + 임시저장 버튼, 제출 후 고정(평가 전까지 제출 취소 가능) |
| 4관점 AI 평가 | 완료(반자동) | 가스기술사·공학박사·채점위원·전문기자 기준과 답변 형식을 담은 평가 프롬프트 생성 → 답변 붙여넣기 → 관점별 점수·의견과 종합의견으로 나눠 확인·수정 후 저장. 종합 점수 = 네 점수 평균. API 직접 호출은 하지 않음 |
| 모범답안 공개 | 완료(반자동) | 평가 저장 뒤에만 열림. A4 1~2쪽·서론-본론-결론 형식 프롬프트(종합 평가의 지적 사항 포함), 세 부분이 빠지면 확인, `[확인 필요]` 표시 개수 경고 |
| 학습 기록·영역별 현황 | 완료 | 날짜별 요약, 문제별 목록(기간·영역·단계 검색), 영역별 현황표(출제·제출·평가 수, 평균·최근 점수, 관점별 평균), 영역별 평균 막대 그래프, 가장 낮은 영역 「취약」 표시 |
| 기록 내보내기 | 완료 | 학습 기록·영역별 현황 CSV, 전체 엑셀(xlsx) 내보내기·가져오기, 날짜별 학습지 인쇄(PDF 저장) |
| AI 자동 평가·모범답안 (09-29 요청) | 완료 | 본인 OpenAI 키(선택)로 답안 제출 시 3·4단계 자동 작성, 모델 선택(기본 gpt-4o-mini). 키 없으면 통합 프롬프트 한 번 → 붙여넣기 → 3·4단계 자동 분배(구분선·JSON). 채점 기준(구성·핵심 키워드·도해·분량)과 답안 글자 수를 프롬프트에 넣음 |
| 사고사례 DB | 1단계 범위(양식만) | 사고 카드 빈 양식(사고명·발생 시기·유형·관련 영역 + 5항목) 저장·수정·삭제·CSV. 내용 채우기·A4 3쪽 분석자료 생성은 2단계 |
| 가스사고 기사 목록 (09-29 요청) | 완료(대안) | 사고 카드 「가스사고 기사」 탭. GitHub Actions 가 매일 공개 RSS(제목·링크·날짜·언론사, 본문 없음)를 받아 `data/news.json` 갱신 → 날짜별 최신순 목록·검색·CSV. 기사 붙여넣기(날짜 읽기·중복 제거·200자 발췌), 「사고 카드로」 초안 만들기. 뉴스 사이트 직접 수집은 브라우저 보안(CORS)으로 불가 — 기획서 11장 |
| 기술 카드 = 공부 노트 (09-29 오후 요청) | 완료 | **제목 + 내용** 두 칸, 저장할 때 목차 11개(연소폭발공학 ~ 저장탱크 · 기타) 중 하나를 고름. 목차를 누르면 그 목차의 카드·내용이 펼쳐짐. 예전 형식(기술명·5항목·출처) 카드와 엑셀은 제목·내용으로 자동 이관 |
| AI 자동 출제 (09-29 오후) | 완료 | 자동 모드 키가 있으면 「오늘의 문제」를 연 날 문제가 없을 때 10문제 자동 출제(설정에서 끄기, 같은 날짜는 한 번만 자동) |
